# Contributing to younit

This repository is maintained by the EFG Hermes Data Science team and is
not currently accepting external contributions (pull requests, forks, etc.).
This may change in the future, but is not the case today.

## Reporting a Bug or Requesting a Feature

Please open a GitHub issue using the appropriate template:

- [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md)
- [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md)

For security vulnerabilities, see [SECURITY.md](SECURITY.md) instead of
opening a public issue.

## Security

Do **not** open public issues for security vulnerabilities. See [SECURITY.md](SECURITY.md).
